# Satoshi Notebook Content

This directory previously contained philosophical insights from satoshinotebook.com.
The feature has been disabled to improve performance.

## Notice

The insights feature is currently disabled. The content JSON file has been removed.
If you wish to re-enable this feature in the future, you'll need to:

1. Re-add the content.json file with appropriate structure
2. Uncomment the feature code in:
   - pages/index.vue
   - pages/send.vue
   - server/api/random-insight.ts

## Performance Impact

Removing this feature significantly improves application loading time and reduces server resource usage.
